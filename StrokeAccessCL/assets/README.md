## Español

Esta carpeta guarda las imágenes que usa el [README del proyecto](../README.md). La aplicación no carga ninguna de ellas: `index.html` dibuja su propio ícono en SVG y trae el logo del DIINF desde `informatica.usach.cl`.

| Archivo | Contenido |
|---|---|
| `logo.svg` | Logo del proyecto: un marcador blanco con una cruz roja sobre fondo azul petróleo. Aparece al inicio del README. |
| `screenshot-main.png` | Captura de la vista principal, de 1918 x 914 píxeles. Aparece al inicio del README y en la sección 4. |
| `screenshot-region.png` | Captura de una región con isócronas activas, de 1919 x 914 píxeles (sección 4). |
| `screenshot-help.png` | Captura de la ventana de ayuda y metodología, de 1915 x 914 píxeles (sección 4). |
| `architecture-code.png` | Diagrama de la arquitectura técnica, de 1400 x 820 píxeles (sección 6). |
| `pipeline-code.png` | Diagrama del flujo de datos y de ejecución, de 1400 x 760 píxeles (secciones 4 y 8). |

Las imágenes se prepararon a partir de los archivos de la aplicación (`index.html`, `css/`, `js/` y `data/`), no de la memoria escrita. Si cambia la interfaz, conviene reemplazar las capturas con el mismo nombre para que los enlaces del README sigan funcionando.

## English

This folder holds the images used by the [project README](../README.md). The application loads none of them: `index.html` draws its own SVG icon and fetches the DIINF logo from `informatica.usach.cl`.

| File | Content |
|---|---|
| `logo.svg` | Project logo: a white map pin with a red cross on a dark teal background. It appears at the top of the README. |
| `screenshot-main.png` | Screenshot of the main view, 1918 x 914 pixels. It appears at the top of the README and in section 4. |
| `screenshot-region.png` | Screenshot of a region with active isochrones, 1919 x 914 pixels (section 4). |
| `screenshot-help.png` | Screenshot of the help and methodology window, 1915 x 914 pixels (section 4). |
| `architecture-code.png` | Technical architecture diagram, 1400 x 820 pixels (section 6). |
| `pipeline-code.png` | Data and runtime flow diagram, 1400 x 760 pixels (sections 4 and 8). |

The images were prepared from the application files (`index.html`, `css/`, `js/` and `data/`), not from the written thesis. When the interface changes, replace the screenshots under the same names so the README links keep working.
