# Checklist rápido para publicar Phily en GitHub

1. Crear repositorio `phily` en GitHub.
2. Subir todos los archivos de este paquete a la raíz del repositorio.
3. Revisar si el nombre público será `Phily` o `Phyli` y dejarlo consistente.
4. Revisar la cita: año, orden de autores y texto institucional.
5. Definir licencia antes de marcar el repositorio como open source.
6. Activar GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).
7. Abrir la URL pública y probar:
   - carga de `examples/simple.nwk`;
   - carga de `examples/vertebrates.nwk`;
   - exportación SVG/PNG;
   - botón Share link.
8. Agregar capturas en `assets/` y actualizar la sección Screenshots del README.
