## Español

Esta carpeta guarda las imágenes de la documentación de [Phyli](../README.md). La aplicación no carga ningún archivo de aquí, porque su código, sus estilos y sus banderas de idioma van dentro de `index.html`.

| Archivo | Qué muestra | Dónde se usa |
|---|---|---|
| `screenshot-main.png` | Filograma rectangular con el ejemplo integrado del árbol de la vida (1600 x 1000 px). | Portada y sección de capturas del `README.md`. |
| `screenshot-radial.png` | Árbol en trazado radial (1600 x 1000 px). | Sección de capturas del `README.md`. |
| `screenshot-network.png` | Red filogenética en Newick extendido (1600 x 1000 px). | Sección de capturas del `README.md`. |
| `screenshot-distance.png` | Medición de distancia entre dos taxones (1600 x 1000 px). | Sección de capturas del `README.md`. |
| `screenshot-export.png` | Panel de exportación (1600 x 1000 px). | Sección de capturas del `README.md`. |
| `screenshot-home.png` | Interfaz con los ejemplos Vertebrados, Simple y Árbol de la vida en la barra lateral, que la página actual ya no ofrece (1440 x 900 px). | Ningún archivo la usa. |
| `flags/cl.svg`, `flags/gb.svg`, `flags/br.svg` | Banderas de Chile, Reino Unido y Brasil en SVG de 64 x 48 con esquinas redondeadas. | Ningún archivo las usa; la página dibuja sus propias banderas en SVG integrado, con otra forma. |

Si se reemplaza una captura que usa el README, conviene mantener su nombre para no romper los enlaces.

## English

This folder stores the documentation images of [Phyli](../README.md). The application loads no file from here, because its code, styles and language flags live inside `index.html`.

| File | What it shows | Where it is used |
|---|---|---|
| `screenshot-main.png` | Rectangular phylogram with the embedded tree of life example (1600 x 1000 px). | Header and screenshot section of `README.md`. |
| `screenshot-radial.png` | Tree in radial layout (1600 x 1000 px). | Screenshot section of `README.md`. |
| `screenshot-network.png` | Phylogenetic network in extended Newick (1600 x 1000 px). | Screenshot section of `README.md`. |
| `screenshot-distance.png` | Distance measurement between two taxa (1600 x 1000 px). | Screenshot section of `README.md`. |
| `screenshot-export.png` | Export panel (1600 x 1000 px). | Screenshot section of `README.md`. |
| `screenshot-home.png` | Interface with the Vertebrados, Simple and Árbol de la vida examples in the sidebar, which the current page no longer offers (1440 x 900 px). | No file uses it. |
| `flags/cl.svg`, `flags/gb.svg`, `flags/br.svg` | Flags of Chile, the United Kingdom and Brazil as 64 x 48 SVG files with rounded corners. | No file uses them; the page draws its own inline SVG flags, with a different shape. |

When a screenshot used by the README is replaced, keep its name so that the links do not break.
