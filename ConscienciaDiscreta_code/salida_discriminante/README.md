## Español

Resultados del paradigma discriminante del manuscrito (Sect. 3.7 y 4.6), generados por `../experimento_discriminante.R` con las soluciones rodilla del régimen limpio del artículo (corrida del 24 de octubre de 2026, `post_hoc/resultados/rodillas_corregidas.csv`). El script es determinista (semillas fijas), así que volver a correrlo reproduce estos archivos.

| Archivo | Contenido |
| --- | --- |
| `discriminante_soa.csv` | Probabilidad de acceder a la sonda por SOA inductor-sonda, arquitectura y condición de onset (aleatorio o fijo), paradigma A. |
| `discriminante_fase.csv` | Prueba logística de dependencia de fase del acceso, con el p de la razón de verosimilitud en el periodo propio de cada arquitectura y en el control de 100 ms, paradigma B. |
| `discriminante_respuesta.csv` | Probabilidad de responder "dos" por SOA y arquitectura en el paradigma A, como apoyo. |
| `fig_discriminante.pdf`, `.png` | Fig. 8 del manuscrito: acceso contra el SOA con onset aleatorio y fijo, y acceso contra la fase del onset. |
| `discriminante_recuperacion.csv` | Solo con el argumento `recovery`: matriz de confusión de la recuperación de modelos sobre este paradigma. |

## English

Results of the discriminating paradigm of the manuscript (Sects. 3.7 and 4.6), generated by `../experimento_discriminante.R` with the clean-regime knee solutions of the paper (run of 24 October 2026, `post_hoc/resultados/rodillas_corregidas.csv`). The script is deterministic (fixed seeds), so running it again reproduces these files.

| File | Content |
| --- | --- |
| `discriminante_soa.csv` | Probability of accessing the probe by inducer-probe SOA, architecture and onset condition (jittered or fixed), paradigm A. |
| `discriminante_fase.csv` | Logistic phase-dependence test of the access, with the likelihood-ratio p value at the own period of each architecture and at the 100 ms control, paradigm B. |
| `discriminante_respuesta.csv` | Probability of a "two" response by SOA and architecture in paradigm A, as support. |
| `fig_discriminante.pdf`, `.png` | Fig. 8 of the manuscript: access against the SOA with jittered and fixed onsets, and access against the onset phase. |
| `discriminante_recuperacion.csv` | Only with the `recovery` argument: confusion matrix of the model recovery on this paradigm. |
