# datos_ejemplo

[Español](#español) · [English](#english)

## Español

Observadores sintéticos generados por el agente de `consciencia_discreta.R`, para probar la ruta de datos reales del script sin datos humanos (por ejemplo, `Rscript consciencia_discreta.R rapido datos_ejemplo/sintetico_periodica.csv`). Cada conjunto tiene 12 observadores generados con una arquitectura; la corrida completa genera los mismos conjuntos, más el de la arquitectura continua modulada, en `salida/datos/`.

| Archivo | Contenido |
| --- | --- |
| `sintetico_continua.csv`, `sintetico_eventos.csv`, `sintetico_periodica.csv` | Un ensayo por fila (3840 por archivo, 320 por observador): `participante`, `isi` (asincronía entre inicios, ms; 0 en los ensayos de un pulso), `n_pulsos` (1 o 2), `respuesta` (1 o 2), `iaf` (frecuencia alfa individual del observador, Hz) y `fase_prestim` (fase del lector o de la modulación al inicio del primer pulso, en radianes). |
| `sintetico_*_parametros.csv` | Parámetros verdaderos de cada observador: `participante`, `generador`, `iaf` y los parámetros de la arquitectura (`tau`, `theta_p`, `m`, `w` y, según el caso, `T` o `theta_g` y `r`). |

## English

Synthetic observers generated by the agent of `consciencia_discreta.R`, to test the real-data path of the script without human data (for example, `Rscript consciencia_discreta.R rapido datos_ejemplo/sintetico_periodica.csv`). Each set has 12 observers generated with one architecture; the full run generates the same sets, plus the one of the modulated continuous architecture, in `salida/datos/`.

| File | Content |
| --- | --- |
| `sintetico_continua.csv`, `sintetico_eventos.csv`, `sintetico_periodica.csv` | One trial per row (3840 per file, 320 per observer): `participante`, `isi` (onset asynchrony, ms; 0 in one-pulse trials), `n_pulsos` (1 or 2), `respuesta` (1 or 2), `iaf` (individual alpha frequency of the observer, Hz) and `fase_prestim` (phase of the reader or of the modulation at the onset of the first pulse, in radians). |
| `sintetico_*_parametros.csv` | True parameters of each observer: `participante`, `generador`, `iaf` and the parameters of the architecture (`tau`, `theta_p`, `m`, `w` and, depending on the case, `T` or `theta_g` and `r`). |
