## English

Figures of the paper as vector PDF, with the numbering of the restructured manuscript: `figuras.R` writes Figs. 2 to 7 and 9 to 17, `Fig1.tex` generates Fig. 1 and `../../experimento_discriminante.R` generates Fig. 8. Figs. 10 to 17 are in the appendix and continue the numbering of the text, as Springer asks. To redo only some of them: `Rscript figuras.R ../salida . figuras Fig3 Fig7`.

| File | Content |
| --- | --- |
| `Fig1.pdf` | Agent and reading architectures. |
| `Fig2.pdf` | One two-pulse trial read by the knee of each architecture in the clean regime. |
| `Fig3.pdf` | Validated Pareto fronts of functional agents, each objective against the cost. |
| `Fig4.pdf` | Intervals between reads in the fronts of functional agents. |
| `Fig5.pdf` | Identifiability of the access scheme (model recovery). |
| `Fig6.pdf` | Psychometric curves of Deodato and Melcher and of each architecture with the ISI read as a blank gap. |
| `Fig7.pdf` | Bound of the periodic reader and thresholds of Haarlem et al. |
| `Fig8.pdf` | Discriminating paradigm: probe access against the inducer-probe SOA (jittered and fixed onsets) and against the onset phase. |
| `Fig9.pdf` | Fraction of forced reading gaps detected by the knee of each architecture. |
| `Fig10.pdf` | Mean Friedman rank of the 27 configurations of the parametrisation. |
| `Fig11.pdf` | Validation of NSGA-III on the clean regime: convergence and validation hypervolume of NSGA-III and of random search over 11 seeds. |
| `Fig12.pdf` | Share of the combined front of each architecture in each seed. |
| `Fig13.pdf` | Two-dimensional Pareto frontiers of NSGA-III and of random search. |
| `Fig14.pdf` | Sensitivity to the assumptions of the stimulus. |
| `Fig15.pdf` | Fitted periods against the alpha period of each synthetic observer. |
| `Fig16.pdf` | AIC of each architecture minus the lowest AIC of each participant of Deodato and Melcher. |
| `Fig17.pdf` | Pre-stimulus instantaneous alpha frequency on correct and incorrect trials (Haarlem et al.). |
