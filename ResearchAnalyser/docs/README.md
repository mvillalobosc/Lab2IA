## Español

Esta carpeta guarda las capturas de pantalla que usa el [README de ResearchAnalyser](../README.md). Las tres están en `screenshots/`, en formato WebP de 1280 × 889 píxeles, y muestran una versión anterior de la interfaz: la portada decía "¿Qué quieres analizar?" y los módulos se llamaban "Analizador Bibliométrico" y "Analizador de Memorias DIINF". La app actual tiene otro diseño, así que conviene reemplazarlas por capturas nuevas cuando se actualice la documentación.

| Archivo | Qué muestra |
|---|---|
| `screenshots/home.webp` | La portada con las dos tarjetas de módulo. |
| `screenshots/publications-overview.webp` | El resumen del módulo Publicaciones. |
| `screenshots/theses-overview.webp` | El resumen del módulo Tesis y memorias. |

Ninguna página de la app carga estas imágenes.

## English

This folder holds the screenshots used by the [ResearchAnalyser README](../README.md). All three are in `screenshots/`, as 1280 × 889 pixel WebP files, and they show an earlier version of the interface: the home page read "¿Qué quieres analizar?" (what do you want to analyse?) and the modules were called "Analizador Bibliométrico" and "Analizador de Memorias DIINF". The current app has a different design, so the screenshots should be replaced with new ones the next time the documentation is updated.

| File | What it shows |
|---|---|
| `screenshots/home.webp` | The home page with the two module cards. |
| `screenshots/publications-overview.webp` | The overview of the Publications module. |
| `screenshots/theses-overview.webp` | The overview of the Theses and projects module. |

No page of the app loads these images.
