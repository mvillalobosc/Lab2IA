## Español

| Archivo | Qué es y quién lo usa |
|---|---|
| `styles.css` | Hoja de estilos única de las tres páginas (`index.html`, `inferencia.html` y `pipeline.html`), de unos 47 KB. Define la paleta corporativa USACH (teal `#00A499`, naranjo `#EA7600`, pizarra `#394049`), los colores geológicos ICS de cada período y las reglas para pantallas móviles. No tiene `url()` ni `@import`. |
| `favicon.svg` | Ícono de la aplicación (un árbol sobre fondo teal). Las tres páginas lo declaran como `rel="icon"` y el `README.md` lo muestra en su cabecera. |
| `readme/screenshot-home.png` | Portada de la suite (1440 x 1000 px). |
| `readme/screenshot-inference.png` | Editor de matriz morfológica del módulo 1 (1440 x 1000 px). |
| `readme/screenshot-pipeline.png` | Pipeline de paisajes topológicos del módulo 2 (1440 x 1000 px). |
| `readme/screenshot-forest.png` | Bosque filogenético del módulo 2 (1440 x 1000 px). |

Las cuatro capturas de `readme/` las usa solo el `README.md` del proyecto, en la cabecera y en la sección de capturas de cada idioma; la aplicación no las carga. Si se reemplaza una, conviene mantener su nombre para no romper los enlaces.

## English

This folder stores the visual identity of [PaleoForest](../README.md) and the screenshots of its documentation.

| File | What it is and who uses it |
|---|---|
| `styles.css` | Single stylesheet for the three pages (`index.html`, `inferencia.html` and `pipeline.html`), about 47 KB. It defines the USACH corporate palette (teal `#00A499`, orange `#EA7600`, slate `#394049`), the ICS geological colours of each period and the rules for mobile screens. It contains no `url()` or `@import`. |
| `favicon.svg` | Application icon (a tree on a teal background). The three pages declare it as `rel="icon"`, and `README.md` shows it in its header. |
| `readme/screenshot-home.png` | Landing page of the suite (1440 x 1000 px). |
| `readme/screenshot-inference.png` | Morphological matrix editor of module 1 (1440 x 1000 px). |
| `readme/screenshot-pipeline.png` | Topological-landscape pipeline of module 2 (1440 x 1000 px). |
| `readme/screenshot-forest.png` | Phylogenetic forest of module 2 (1440 x 1000 px). |

Only the project `README.md` uses the four screenshots in `readme/`, in the header and in the screenshot section of each language; the application does not load them. When one is replaced, keep its name so that the links do not break.
