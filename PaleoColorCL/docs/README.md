## Español

Esta carpeta guarda material de apoyo para la documentación de [PaleoColor CL](../README.md). La aplicación no carga nada desde aquí.

| Archivo | Qué muestra |
|---|---|
| `screenshots/01-inicio.png` | Pantalla de inicio del visor (`index.html`). |
| `screenshots/02-plantillas.png` | Galería de plantillas (`plantillas.html`) con sus filtros. |
| `screenshots/03-como-funciona.png` | Ayuda "Cómo funciona" del visor. |

Las tres capturas son PNG de 1440 x 920 px y las usa solo el `README.md` del proyecto, en la portada y en la sección de capturas de cada idioma. Si se reemplaza una captura, conviene mantener el nombre para que los enlaces del README sigan funcionando.

## English

This folder holds supporting material for the [PaleoColor CL](../README.md) documentation. The application loads nothing from here.

| File | What it shows |
|---|---|
| `screenshots/01-inicio.png` | Start screen of the viewer (`index.html`). |
| `screenshots/02-plantillas.png` | Template gallery (`plantillas.html`) with its filters. |
| `screenshots/03-como-funciona.png` | "How it works" help screen of the viewer. |

The three screenshots are 1440 x 920 px PNG files, and only the project `README.md` uses them, in the header and in the screenshot section of each language. When a screenshot is replaced, keep its name so that the README links keep working.
