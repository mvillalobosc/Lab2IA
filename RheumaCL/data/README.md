## Español

Esta carpeta trae las dos bases de datos que el dashboard carga al abrir. Cada archivo es JavaScript que asigna un objeto a una variable global de `window`, de modo que `index.html` los carga con etiquetas `<script>` y la página funciona sin servidor. Los dos los genera [`tools/preparar_datos.R`](../tools/README.md) y no se editan a mano. Para el contexto general, revisa el [README del proyecto](../README.md).

| Archivo | Tamaño | Variable global | Contenido |
|---|---|---|---|
| `bd_encuesta.js` | 71 KB | `window.BD_ENCUESTA` | Conteos y porcentajes de la encuesta, por enfermedad y por región. |
| `bd_regiones.js` | 88 KB | `window.BD_REGIONES` | Contorno simplificado de las 16 regiones de Chile para el mapa. |

La versión incluida se generó el 16 de noviembre de 2026 a partir de `data_encuesta_filtrado.xlsx` (1.151 personas, 116 columnas). La base trae solo agregados: no tiene filas de personas.

### `bd_encuesta.js`

| Clave | Contenido |
|---|---|
| `meta` | Fecha de generación, número de encuestados, de preguntas, de enfermedades y de regiones. |
| `enfermedades` | Los códigos de las 12 enfermedades (`V8` a `V18` y `V20`). |
| `regiones` | Los códigos oficiales de las 16 regiones, de norte a sur. |
| `red` | `nodos` (enfermedad, encuestados, número de enfermedades con que se combina y nivel) y `aristas` (dos enfermedades y cuántas personas declaran ambas). |
| `porEnfermedad` | Un objeto por enfermedad con `n`, `prev` y los grupos `resumen`, `combinada`, `perfil`, `tratamientos` y `acceso`. |
| `porRegion` | Un objeto por región con `n`, `pct_muestra`, los indicadores de traslado, discapacidad y credencial, las enfermedades declaradas y las tablas de sexo, edad, educación e indicadores comunales. |

Cada tabla tiene la forma `{base, sin_respuesta, filas}`: `base` es el número de personas del grupo que respondió la pregunta, `sin_respuesta` las que no respondieron y `filas` una lista de `[código, personas, porcentaje]`. El porcentaje se calcula sobre `base` y viene con un decimal. Los códigos de las respuestas se traducen en `js/textos.js`.

Las cifras se compararon con las fórmulas del dashboard Shiny original: de 1.459 cifras revisadas, todas coincidieron, salvo la corrección de la pregunta V114 que explica el README del proyecto.

### `bd_regiones.js`

Trae `ancho` y `alto` (el `viewBox` del mapa) y `regiones`, una lista con el código de cada región (`cod`), su contorno como ruta SVG (`d`) y el punto donde va su marca (`cx`, `cy`). El contorno se proyecta con Mercator y se simplifica con Douglas-Peucker. El mapa no dibuja las islas oceánicas ni las islas muy pequeñas, para que el territorio continental se lea bien en una columna angosta.

## English

This folder holds the two databases that the dashboard loads when it opens. Each file is JavaScript that assigns an object to a global `window` variable, so `index.html` loads them through `<script>` tags and the page works without a server. Both are generated by [`tools/preparar_datos.R`](../tools/README.md) and are not edited by hand. For the general context, see the [project README](../README.md).

| File | Size | Global variable | Content |
|---|---|---|---|
| `bd_encuesta.js` | 71 KB | `window.BD_ENCUESTA` | Counts and percentages of the survey, by disease and by region. |
| `bd_regiones.js` | 88 KB | `window.BD_REGIONES` | Simplified outline of the 16 regions of Chile for the map. |

The included version was generated on 16 November 2026 from `data_encuesta_filtrado.xlsx` (1,151 people, 116 columns). The database holds aggregates only: it has no rows of people.

### `bd_encuesta.js`

| Key | Content |
|---|---|
| `meta` | Generation date and number of respondents, questions, diseases and regions. |
| `enfermedades` | The codes of the 12 diseases (`V8` to `V18` and `V20`). |
| `regiones` | The official codes of the 16 regions, from north to south. |
| `red` | `nodos` (disease, respondents, number of diseases it combines with and level) and `aristas` (two diseases and how many people report both). |
| `porEnfermedad` | One object per disease with `n`, `prev` and the groups `resumen`, `combinada`, `perfil`, `tratamientos` and `acceso`. |
| `porRegion` | One object per region with `n`, `pct_muestra`, the indicators for travel, disability and disability card, the reported diseases and the tables for sex, age, education and commune indicators. |

Every table has the form `{base, sin_respuesta, filas}`: `base` is the number of people in the group who answered the question, `sin_respuesta` those who did not, and `filas` a list of `[code, people, percentage]`. The percentage is computed over `base` and has one decimal. The answer codes are translated in `js/textos.js`.

The figures were compared with the formulas of the original Shiny dashboard: of the 1,459 figures reviewed, all matched, except for the correction of question V114 explained in the project README.

### `bd_regiones.js`

It holds `ancho` and `alto` (the `viewBox` of the map) and `regiones`, a list with the code of each region (`cod`), its outline as an SVG path (`d`) and the point where its mark goes (`cx`, `cy`). The outline is projected with Mercator and simplified with Douglas-Peucker. The map does not draw the oceanic islands or the very small islands, so that the mainland reads well in a narrow column.
