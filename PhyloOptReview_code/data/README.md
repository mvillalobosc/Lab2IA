## Español

`raw/` guarda las cadenas de búsqueda, y `processed/` las bases intermedias y finales que escriben los scripts. Las exportaciones de Scopus y Web of Science no se distribuyen (ver `raw/README.md`).

## English

`raw/` holds the search strings, and `processed/` the intermediate and final databases written by the scripts. The Scopus and Web of Science exports are not distributed (see `raw/README.md`).
