## Español

Matrices de métodos que publica el artículo, condensadas a partir de `../verification/`. `08_tables.R` las convierte en las tablas en LaTeX de `../results/latex/`.

| Archivo | Tabla del artículo |
| --- | --- |
| `ls_table.csv` | Búsqueda local y otras propuestas monoobjetivo que no son metaheurísticas (Tabla D.1) |
| `so_table.csv` | Metaheurísticas monoobjetivo (Tabla D.2) |
| `mo_table.csv` | Estrategias multiobjetivo (Tabla D.3); `code` indica si se encontró código fuente público (`Yes` o `n.f.`) y `code_source` dónde |
