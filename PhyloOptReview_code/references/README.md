# references

[Español](#español) · [English](#english)

## Español

`classics.bib` guarda las referencias de contexto del manuscrito, que no son registros de la búsqueda, verificadas a mano. Sus claves `B#####` siguen el orden de la primera cita en el manuscrito, y un comentario sobre cada entrada indica el primer autor y el año. `../R/10_bib.R` las copia en el `references.bib` del manuscrito.

## English

`classics.bib` holds the background references of the manuscript, which are not search records, verified by hand. Their `B#####` keys follow the order of the first citation in the manuscript, and a comment above each entry gives the first author and the year. `../R/10_bib.R` copies them into the `references.bib` of the manuscript.
