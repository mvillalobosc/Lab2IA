# results/tree

[Español](#español) · [English](#english)

## Español

| Archivo | Contenido |
| --- | --- |
| `literature_tree_nj.nwk` | Árbol de la literatura en Newick; las hojas son los identificadores de los estudios y los nodos internos llevan sus caracteres distintivos |
| `literature_tree_nj.json` | El mismo árbol en JSON, con los metadatos de cada hoja |
| `literature_tree_nj.pdf`, `literature_tree_nj.png` | Figura del árbol (Fig. 7) |
| `highlighted_clades.csv` | Los 23 clados destacados, con tamaño, bloque, pureza y caracteres compartidos |
| `internal_nodes.csv` | Todos los nodos internos con su tamaño, etiqueta, bloque mayoritario y pureza |
| `tree.rds` | Objeto de R con el árbol, los nodos y los clados, que leen los pasos siguientes |

## English

| File | Content |
| --- | --- |
| `literature_tree_nj.nwk` | Literature tree in Newick; the leaves are the study identifiers and the internal nodes carry their distinctive characters |
| `literature_tree_nj.json` | The same tree in JSON, with the metadata of each leaf |
| `literature_tree_nj.pdf`, `literature_tree_nj.png` | Figure of the tree (Fig. 7) |
| `highlighted_clades.csv` | The 23 highlighted clades, with size, block, purity and shared characters |
| `internal_nodes.csv` | All internal nodes with their size, label, majority block and purity |
| `tree.rds` | R object with the tree, nodes and clades, read by the following steps |
