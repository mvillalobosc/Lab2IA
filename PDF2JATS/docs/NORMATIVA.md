# Normativa y servicios utilizados

La interfaz centraliza estos enlaces en **Ayuda → Normativa y ayudas oficiales**.

## SciELO Publishing Schema

- Guía: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/
- Identificadores (`article-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-article-id.html
- Licencia (`license`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-license.html
- ORCID (`contrib-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-contrib-id.html
- Secciones (`sec`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-sec.html
- Referencias (`ref-list`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-ref-list.html
- Cambios de SciELO PS 1.10: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt_BR/master/whatsnew-1.10.html

## JATS

- JATS 1.3: https://jats.nlm.nih.gov/1.3/
- Journal Publishing Tag Set 1.3: https://jats.nlm.nih.gov/publishing/1.3/

## DOI y metadatos

- DOI Foundation / DOI Handbook: https://www.doi.org/doi-handbook/html/
- Crossref REST API: https://www.crossref.org/documentation/retrieve-metadata/rest-api/
- DataCite REST API: https://support.datacite.org/docs/api

## Nota

Los servicios externos pueden devolver metadatos incompletos o diferentes entre sí. PDF2JATS los usa como apoyo para completar la ficha, pero mantiene la revisión editorial como etapa final antes de generar el XML.
