# Normativa y servicios utilizados · Standards and services used

[Español](#español) · [English](#english)

## Español

La interfaz muestra en **Ayuda → Normativa y ayudas oficiales** los seis primeros enlaces de SciELO Publishing Schema de esta lista (guía, identificadores, licencia, ORCID, secciones y referencias). Este documento reúne además las otras normas y servicios con que trabaja el proyecto.

### SciELO Publishing Schema

- Guía: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/
- Identificadores (`article-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-article-id.html
- Licencia (`license`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-license.html
- ORCID (`contrib-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-contrib-id.html
- Secciones (`sec`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-sec.html
- Referencias (`ref-list`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-ref-list.html
- Cambios de SciELO PS 1.10: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt_BR/master/whatsnew-1.10.html

### JATS

- JATS 1.3: https://jats.nlm.nih.gov/1.3/
- Journal Publishing Tag Set 1.3: https://jats.nlm.nih.gov/publishing/1.3/

### DOI y metadatos

- DOI Foundation / DOI Handbook: https://www.doi.org/doi-handbook/html/
- Crossref REST API: https://www.crossref.org/documentation/retrieve-metadata/rest-api/
- DataCite REST API: https://support.datacite.org/docs/api

### Nota

Los servicios externos pueden devolver metadatos incompletos o diferentes entre sí. PDF2JATS los usa como apoyo para completar la ficha, pero mantiene la revisión editorial como etapa final antes de generar el XML.

## English

The interface shows, in **Ayuda → Normativa y ayudas oficiales** (help, official standards and guides), the first six SciELO Publishing Schema links of this list (guide, identifiers, licence, ORCID, sections and references). This document also gathers the other standards and services the project works with.

### SciELO Publishing Schema

- Guide: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/
- Identifiers (`article-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-article-id.html
- Licence (`license`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-license.html
- ORCID (`contrib-id`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-contrib-id.html
- Sections (`sec`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-sec.html
- References (`ref-list`): https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt-br/master/tagset/elemento-ref-list.html
- Changes in SciELO PS 1.10: https://scielo.readthedocs.io/projects/scielo-publishing-schema/pt_BR/master/whatsnew-1.10.html
