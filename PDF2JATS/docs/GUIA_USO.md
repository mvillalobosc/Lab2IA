# Guía de uso · User guide

[Español](#español) · [English](#english)

## Español

### 1. Cargar artículos

Haz clic en **+ Agregar PDFs** o arrastra uno o varios documentos a la zona de carga. Puedes agregar más PDF posteriormente sin reiniciar la sesión.

Durante el procesamiento aparece una ventana con el archivo actual, el contador y el avance general.

### 2. Revisar estados

Los bloques pueden aparecer con:

- `×`: falta un dato requerido.
- `?`: el dato debe comprobarse.
- `✓`: el dato ya fue revisado.

**Para confirmar un bloque con `?`, haz clic directamente sobre el símbolo.** Cambiará a `✓`. Al modificar un campo, la aplicación también lo considera revisado.

### 3. Trabajar por pestañas

#### Metadatos

Revisa revista, editorial, ISSN, DOI, volumen, número, páginas, fechas, licencia, títulos, resúmenes y palabras clave.

La URL de Creative Commons no se escribe manualmente: se deriva de la licencia seleccionada.

#### Autoría

Revisa nombres, ORCID, correos y asociaciones con filiaciones. Las filiaciones pueden corregirse y enriquecerse con identificadores cuando estén disponibles.

#### Contenido

Edita la estructura de secciones y párrafos. Si una línea fue interpretada erróneamente como encabezado, usa **Convertir en párrafo** para incorporarla a la sección anterior sin perder el texto.

#### Referencias

Cada referencia puede corregirse manualmente. También puedes buscar DOI y aplicar una coincidencia bibliográfica.

#### Salida XML

Previsualiza el XML y descarga el artículo actual. La descarga global reúne los XML de los artículos cargados.

El selector **Estándar de salida** ofrece tres perfiles: SciELO PS 1.10 (el que viene elegido), NISO JATS 1.3 y Clarivate / SciELO CI. El perfil elegido define qué campos se exigen en la ficha y qué XML se descarga. Clarivate / SciELO CI solo lleva metadatos, sin el cuerpo del artículo, y se descarga en ISO-8859-1.

### 4. PID SciELO

El PID no debe inventarse ni escribirse manualmente. Si el artículo ya está publicado en SciELO, la aplicación puede intentar recuperarlo a partir del DOI. Si el artículo todavía no está incorporado en SciELO, el dato se deja vacío.

### 5. Normativa

Los enlaces a normas se encuentran exclusivamente en **Ayuda → Normativa y ayudas oficiales**. De esta forma, los avisos amarillos se concentran en la tarea editorial y no repiten enlaces en cada observación.

### 6. Atajos de teclado

| Tecla | Acción |
|---|---|
| Enter | Ir al siguiente campo pendiente. |
| Ctrl + ↓ | Ir al artículo siguiente. |
| Ctrl + ↑ | Volver al artículo anterior. |
| ← / → | Cambiar de página del PDF cuando no estás escribiendo. |

## English

The interface is in Spanish; the names in bold are the labels you will see on screen.

### 1. Upload articles

Click **+ Agregar PDFs** (add PDFs) or drag one or several documents onto the upload area. You can add more PDFs later without restarting the session.

While the files are processed, a window shows the current file, the counter and the progress of the whole upload.

### 2. Review the states

Blocks can show:

- `×`: a required value is missing.
- `?`: the value must be checked.
- `✓`: the value has been reviewed.

**To confirm a block marked `?`, click the symbol itself.** It changes to `✓`. When you edit a field, the application also treats it as reviewed.

### 3. Work by tabs

#### Metadatos (metadata)

Check the journal, publisher, ISSN, DOI, volume, issue, pages, dates, licence, titles, abstracts and keywords.

The Creative Commons URL is not typed by hand: it is derived from the selected licence.

#### Autoría (authorship)

Check names, ORCID, e-mail addresses and the links to affiliations. Affiliations can be corrected and enriched with identifiers when available.

#### Contenido (content)

Edit the structure of sections and paragraphs. If a line was wrongly read as a heading, use **Convertir en párrafo** (convert into paragraph) to move it into the previous section without losing the text.

#### Referencias (references)

Each reference can be corrected by hand. You can also look up its DOI and apply a bibliographic match.

#### Salida XML (XML output)

Preview the XML and download the current article. The global download gathers the XML of all uploaded articles.

The **Estándar de salida** (output standard) selector offers three profiles: SciELO PS 1.10 (selected at start), NISO JATS 1.3 and Clarivate / SciELO CI. The chosen profile defines which fields the record requires and which XML is downloaded. Clarivate / SciELO CI carries metadata only, without the article body, and is downloaded in ISO-8859-1.

### 4. SciELO PID

The PID must not be invented or typed by hand. If the article is already published in SciELO, the application can try to retrieve it from the DOI. If the article has not been added to SciELO, the field stays empty.

### 5. Standards

Links to standards are only in **Ayuda → Normativa y ayudas oficiales** (help, official standards and guides). This keeps the yellow warnings focused on the editorial task instead of repeating links in every observation.

### 6. Keyboard shortcuts

| Key | Action |
|---|---|
| Enter | Go to the next pending field. |
| Ctrl + ↓ | Go to the next article. |
| Ctrl + ↑ | Go back to the previous article. |
| ← / → | Change the PDF page when you are not typing. |
