# Guía de uso

## 1. Cargar artículos

Haz clic en **+ Agregar PDFs** o arrastra uno o varios documentos a la zona de carga. Puedes agregar más PDF posteriormente sin reiniciar la sesión.

Durante el procesamiento aparece una ventana con el archivo actual, el contador y el avance general.

## 2. Revisar estados

Los bloques pueden aparecer con:

- `×`: falta un dato requerido.
- `?`: el dato debe comprobarse.
- `✓`: el dato ya fue revisado.

**Para confirmar un bloque con `?`, haz clic directamente sobre el símbolo.** Cambiará a `✓`. Al modificar un campo, la aplicación también lo considera revisado.

## 3. Trabajar por pestañas

### Metadatos

Revisa revista, editorial, ISSN, DOI, volumen, número, páginas, fechas, licencia, títulos, resúmenes y palabras clave.

La URL de Creative Commons no se escribe manualmente: se deriva de la licencia seleccionada.

### Autoría

Revisa nombres, ORCID, correos y asociaciones con filiaciones. Las filiaciones pueden corregirse y enriquecerse con identificadores cuando estén disponibles.

### Contenido

Edita la estructura de secciones y párrafos. Si una línea fue interpretada erróneamente como encabezado, usa **Convertir en párrafo** para incorporarla a la sección anterior sin perder el texto.

### Referencias

Cada referencia puede corregirse manualmente. También puedes buscar DOI y aplicar una coincidencia bibliográfica.

### Salida XML

Previsualiza el XML y descarga el artículo actual. La descarga global reúne los XML de los artículos cargados.

## 4. PID SciELO

El PID no debe inventarse ni escribirse manualmente. Si el artículo ya está publicado en SciELO, la aplicación puede intentar recuperarlo a partir del DOI. Si el artículo todavía no está incorporado en SciELO, el dato se deja vacío.

## 5. Normativa

Los enlaces a normas se encuentran exclusivamente en **Ayuda → Normativa y ayudas oficiales**. De esta forma, los avisos amarillos se concentran en la tarea editorial y no repiten enlaces en cada observación.
