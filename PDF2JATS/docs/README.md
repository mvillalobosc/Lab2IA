## Español

Esta carpeta reúne la documentación de PDF2JATS que no cabe en el [README del proyecto](../README.md). Cada documento está en castellano y en inglés.

| Documento | Contenido |
|---|---|
| [GUIA_USO.md](GUIA_USO.md) | Cómo cargar artículos, leer los estados `×`, `?` y `✓`, trabajar por pestañas, elegir el perfil de salida, tratar el PID de SciELO y usar los atajos de teclado. |
| [ARQUITECTURA.md](ARQUITECTURA.md) | Componentes (`app.py`, `core/`, `emisores/` y `web/index.html`), flujo de datos desde el PDF hasta el XML y el principio de diseño de la revisión humana. |
| [INSTALACION.md](INSTALACION.md) | Instalación en un servidor: entorno virtual, prueba con Gunicorn, unidad de systemd, proxy inverso con Apache y uso de `ACTIVAR.sh`. |
| [NORMATIVA.md](NORMATIVA.md) | Enlaces oficiales de SciELO Publishing Schema, JATS, DOI, Crossref y DataCite. |

La subcarpeta `images/` tiene las tres capturas de pantalla que muestra el README del proyecto: `01-inicio.png` (pantalla inicial), `02-ayuda-normativa.png` (panel de ayuda con la normativa y los estados) y `03-carga-multiple.png` (ventana de progreso de una carga de varios PDF).

## English

This folder gathers the PDF2JATS documentation that does not fit in the [project README](../README.md). Each document is in Spanish and English.

| Document | Content |
|---|---|
| [GUIA_USO.md](GUIA_USO.md) | How to upload articles, read the `×`, `?` and `✓` states, work by tabs, choose the output profile, handle the SciELO PID and use the keyboard shortcuts. |
| [ARQUITECTURA.md](ARQUITECTURA.md) | Components (`app.py`, `core/`, `emisores/` and `web/index.html`), data flow from the PDF to the XML and the design principle of human review. |
| [INSTALACION.md](INSTALACION.md) | Installation on a server: virtual environment, Gunicorn test, systemd unit, Apache reverse proxy and use of `ACTIVAR.sh`. |
| [NORMATIVA.md](NORMATIVA.md) | Official links for the SciELO Publishing Schema, JATS, DOI, Crossref and DataCite. |

The `images/` subfolder holds the three screenshots shown in the project README: `01-inicio.png` (start screen), `02-ayuda-normativa.png` (help panel with the standards and the states) and `03-carga-multiple.png` (progress window while several PDFs upload).
