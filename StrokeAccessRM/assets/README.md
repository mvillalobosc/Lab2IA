## Español

Esta carpeta guarda las seis capturas de pantalla que muestra la sección «Capturas / Screenshots» del [README del proyecto](../README.md). La aplicación no carga ninguna de ellas. Todas son PNG de 1600 x 1000 píxeles.

| Archivo | Qué muestra |
|---|---|
| `screenshot-home.png` | La vista principal del visor. |
| `screenshot-guide.png` | La guía inicial, que aparece al abrir la aplicación hasta que el usuario marca la opción de no volver a mostrarla. |
| `screenshot-comuna.png` | El resumen de la comuna de Santiago. |
| `screenshot-network.png` | Los establecimientos y las isócronas de viaje. |
| `screenshot-query.png` | La consulta de una zona censal y los hospitales cercanos. |
| `screenshot-help.png` | La ventana de ayuda y metodología. |

Si cambia la interfaz, conviene reemplazar las capturas con el mismo nombre para que el README siga mostrándolas.

## English

This folder holds the six screenshots shown in the "Capturas / Screenshots" section of the [project README](../README.md). The application loads none of them. All of them are 1600 x 1000 pixel PNG files.

| File | What it shows |
|---|---|
| `screenshot-home.png` | The main view of the viewer. |
| `screenshot-guide.png` | The welcome guide, which appears when the application opens until the user ticks the option not to show it again. |
| `screenshot-comuna.png` | The summary of the municipality of Santiago. |
| `screenshot-network.png` | The facilities and the travel-time isochrones. |
| `screenshot-query.png` | The query of a census zone and the nearby hospitals. |
| `screenshot-help.png` | The help and methodology window. |

When the interface changes, replace the screenshots under the same names so the README keeps showing them.
